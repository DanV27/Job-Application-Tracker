# Job-Application-Tracker
Job application tracker to replace my excel sheet I use everyday.

Tech stack:

Frontend: React (via Vite — way faster/simpler than Create React App)
Backend: FastAPI (Python, so you're not learning a new backend language too)
Database: PostgreSQL — but hosted (Supabase or Railway have free tiers), so no local Docker needed yet
Styling: Tailwind CSS (fast to pick up, looks clean without much effort)
Deploy: Vercel (frontend) + Railway or Render (backend)
